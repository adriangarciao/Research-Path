# Experience-weight sweep (D09)

Balanced focus. Overviews = papers marked as review/survey by type or title (weak cue) in the Beginner / Intermediate / Advanced selections. Shared = papers in common with Intermediate. Criteria fixed before the sweep: overview counts ordered B ≥ I ≥ A; Beginner and Advanced each share ≥ 60% of papers with Intermediate (a nudge, not a different path); Advanced keeps ≥ 1 overview when Intermediate has ≥ 2. Chosen weight: 0.02.
