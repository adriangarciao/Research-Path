# Ablation (M14)

Each variant changes one part of the optimizer and selects from the same frozen pool and budget. All selections are measured with the same reference concept model (combined topics + keywords, concept policy v1) and the original candidate data. Coverage is weighted concept coverage of the eligible pool (the optimizer's own target for the combined variants, so partly circular). Δ = variant − default. Overlap = papers shared with the default selection. Landmarks = how many of the pool's 5 most-cited works are kept. Variants:

- `DEFAULT`: Default: combined concepts, coverage + quality (β = 4)
- `TOPICS_ONLY`: Coverage of OpenAlex topics only
- `KEYWORDS_ONLY`: Coverage of OpenAlex keywords only
- `COVERAGE_ONLY`: Coverage only (β = 0, no quality term)
- `NO_COVERAGE`: Quality only (no coverage term)
- `NO_INFLUENCE`: Citation percentile hidden (neutral)
- `RECENT`: Recent focus
- `RECENT_NO_YEAR`: Recent focus with publication years hidden
- `BEST_BASELINE`: the simple ranking with the highest coverage for that dataset and budget (M08)
