Milestone: M04 — Normalize metadata and expose data-quality evidence
Status: PASS (verified 2026-10-17)
Changed: `publication/` (`OpenAlexWorkNormalizer` v2, `NormalizedWork`, `NormalizationResult`,
`TextNormalization`, `UrlSafety`), `V3__normalization_bounds.sql`, `SnapshotRepository`/`SnapshotSummary`
(quality fields), `scripts/snapshot-report.ps1`, tests.

Implemented (observed):
- Normalizes work id, DOI, title (original kept + normalized key), authors, year/date/type, URLs,
  referenced work IDs, topics/keywords with confidence, abstract rebuilt from the inverted index only when
  supplied.
- Supplied vs unknown kept distinct: missing values stay NULL; confidence outside [0, 1] → unknown;
  `references_supplied` separates "empty list" from "no list"; `abstract_truncated`, `author_count` recorded;
  retrieval time and normalizer version stored with snapshots.
- URL safety (`UrlSafety`): only absolute http(s) with host, no credentials/control chars, ≤ 2048 chars;
  interior spaces encoded as %20 (two real OA links needed it). Link preference: OA → DOI → landing page,
  labelled by kind.
- Bounds: record ≤ 512 KB (reject), title ≤ 1000 (reject), abstract ≤ 20000 (truncate at word + flag),
  authors ≤ 100 stored (total kept).
- Quality summary per snapshot (abstract, topics, keywords, authors, year, DOI, safe source link, reference
  list supplied / non-empty, truncated abstracts, distinct labels, primary-topic concentration, internal
  citation edges, possible duplicate pairs, rejections) and a repeatable report command
  `scripts/snapshot-report.ps1` (independent of the web UI).
