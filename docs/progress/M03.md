Implemented (observed):
- Narrow server-side client: bounded search (`per_page` ≤ 100, page ≥ 1), selected fields only
  (`WORK_FIELDS`), typed `OpenAlexException` with provider status.
- Connect 5 s / read 30 s timeouts; finite retries (3 attempts) for 429, 5xx and network errors with
  exponential backoff capped at 30 s and Retry-After honoured (capped); other 4xx fail immediately.
- Response bodies bounded before parsing (8 MB; declared oversize rejected before reading; oversize not
  retried); 200 responses must be an object with a `results` array.
- Key sent only as `Authorization: Bearer` (never in URLs); `OpenAlexProperties.toString()` redacts it;
  exception messages never echo response bodies.
- Base URL fixed by configuration; topic text is a URL-encoded query value only.
