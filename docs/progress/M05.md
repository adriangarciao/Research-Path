Implemented (observed):
- Exact identity first: OpenAlex id (unique); same DOI + same normalized title → SAME_WORK. A missing DOI
  never matches another missing DOI; same DOI with different titles → UNRESOLVED (kept).
- Possible-duplicate classification from normalized title, shared authors (OpenAlex id or surname + first
  initial), year gap and DOI relation. Same-title works are never merged on title alone.
- Decisions (decision, rule, evidence details, policy version) frozen per snapshot; each member records its
  canonical publication. Nothing is merged or deleted; suppressed members keep raw records as provenance.
- Canonical representative: DOI, open-access link, safe source link, abstract, metadata completeness, then
  lowest OpenAlex id — never citation counts.
- Diagnostics endpoint and report section list every decision with evidence and every suppressed member.

Known limitations (documented, accepted under the conservative policy):
- Versions (preprint/journal, republished chapters) are not suppressed; both can be candidates. Whether the
  optimizer should treat PROBABLE_VERSION as a soft constraint is a **M09 question**.
- Year mismatches and wrong author metadata defeat the rules by design (missed duplicates 13, 16).
- Detection uses exact normalized titles; near-title versions are not detected (fuzzy matching would have
  falsely merged CASP rounds VII/VIII).
- No same-DOI pair observed in real data yet (unit-tested only). One stored DOI ends in "." (left unchanged).
