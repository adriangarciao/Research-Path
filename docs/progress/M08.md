Implemented (observed):
- Offline runner over frozen datasets exported from snapshots; no network, DB or Spring during a run.
- Baselines: RELEVANCE (gate coverage → title-term share → provider rank), CITATION (raw counts; unknown ranked
  after all known; no age/field normalization in v1), PROVIDER_ORDER. Deterministic tie-breaks.
- Metrics with explicit denominators: weighted concept coverage, concepts covered, relevance min/mean, title-term
  share, redundancy (Jaccard, repeats), citation known share/median/top-quartile share, years, link and OA share,
  duplicate DOIs, selection runtime (measured around selection only).
- Each run records dataset file + SHA-256, snapshot id, candidate count, dataset format, snapshot policy versions,
  concept and text-pipeline versions, environment, timestamp, selected ids.
