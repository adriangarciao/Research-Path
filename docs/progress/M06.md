Implemented (observed):
- Relevance evidence from the exact query vs title, confident keywords/topics and abstract (provider rank and
  score recorded, never decisive; citations not used). Tiers ELIGIBLE / TANGENTIAL / BORDERLINE / INELIGIBLE
  with inspectable reasons (matched/missing terms, aspect cues). Abstract never required.
- Only ELIGIBLE members that are not suppressed duplicates are optimization candidates.
- Each member freezes its normalized record; later milestones read candidates from frozen inputs only.
- Topics without a meaningful word rejected before any provider call; snapshot warnings for no / few (< 20)
  eligible candidates and single-term (broad) queries.
